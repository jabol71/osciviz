# Skróty klawiszowe

Na macOS ⌘ to klawisz Command. Skróty płótna (strzałki, R, +/−, G, Tab) działają, gdy płótno
ma fokus (kliknij w nie).

| Skrót | Akcja |
|---|---|
| Spacja | Odtwórz / pauza (przytrzymana + przeciąganie — przesuwa widok) |
| ⌘Z / ⇧⌘Z | Cofnij / ponów |
| ⌘N / ⌘O / ⌘S | Nowy / otwórz / zapisz projekt |
| ⌥⌘S | Zapisz jako |
| ⌘I | Importuj audio |
| ⌘E | Eksport MP4 |
| ⇧⌘S | Zrzut PNG |
| ⌘D | Duplikuj zaznaczone |
| ⌫ / Delete | Usuń zaznaczone |
| ⌘A / Esc | Zaznacz wszystko / odznacz |
| ⌘] / ⌘[ | Warstwa wyżej / niżej |
| Strzałki / ⇧ + strzałki | Przesuń o 0,01 / 0,1 |
| R / ⇧R | Obróć o +5° / −5° |
| + / − | Skaluj o 5% |
| G | Pokaż / ukryj siatkę |
| Tab / ⇧Tab | Następna / poprzednia warstwa |
| ⌘0 | Dopasuj kadr do okna |
| ⌘+ / ⌘− | Przybliż / oddal |
| Home | Na początek utworu |
| ⌘, | Ustawienia |
