# Skróty klawiszowe

Na macOS ⌘ to klawisz Command, ⇧ to Shift, ⌥ to Option. Na Windows te same skróty używają Ctrl, Shift i Alt.
Skróty płótna (strzałki, R, +/−, G, Tab) działają, gdy płótno
ma fokus (kliknij w nie).

| macOS | Windows | Akcja |
|---|---|---|
| Spacja | Spacja | Odtwórz / pauza (przytrzymana + przeciąganie — przesuwa widok) |
| ⌘Z / ⇧⌘Z | Ctrl+Z / Ctrl+Shift+Z | Cofnij / ponów |
| ⌘N / ⌘O / ⌘S | Ctrl+N / Ctrl+O / Ctrl+S | Nowy / otwórz / zapisz projekt |
| ⌥⌘S | Ctrl+Alt+S | Zapisz jako |
| ⌘I | Ctrl+I | Importuj audio |
| ⌘E | Ctrl+E | Eksport MP4 |
| ⇧⌘S | Ctrl+Shift+S | Zrzut PNG |
| ⌘D | Ctrl+D | Duplikuj zaznaczone |
| ⌫ / Delete | Backspace / Delete | Usuń zaznaczone |
| ⌘A / Esc | Ctrl+A / Esc | Zaznacz wszystko / odznacz |
| ⌘] / ⌘[ | Ctrl+] / Ctrl+[ | Warstwa wyżej / niżej |
| Strzałki / ⇧ + strzałki | Strzałki / ⇧ + strzałki | Przesuń o 0,01 / 0,1 |
| R / ⇧R | R / Shift+R | Obróć o +5° / −5° |
| + / − | + / − | Skaluj o 5% |
| G | G | Pokaż / ukryj siatkę |
| Tab / ⇧Tab | Tab / Shift+Tab | Następna / poprzednia warstwa |
| ⌘0 | Ctrl+0 | Dopasuj kadr do okna |
| ⌘+ / ⌘− | Ctrl++ / Ctrl+− | Przybliż / oddal |
| Home | Home | Na początek utworu |
| ⌘, | Ctrl+, | Ustawienia |
